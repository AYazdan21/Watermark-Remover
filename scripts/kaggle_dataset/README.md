# scripts/kaggle_dataset

`generate_dataset.py` in this directory is a byte-identical copy of the
generator that actually produced the user's Kaggle dataset ("train and
test2" -> `wm_dataset_colab/wm_dataset_out`), originally at
`C:\Users\Amirreza Yazdanpanah\Desktop\dataset\scripts\generate_dataset.py`.

It **must stay byte-identical** to that original. `replay_alpha_targets.py`
in this directory works by re-running this exact file with `random`/
`np.random` seeded the same way and monkeypatching a few of its functions
to also carry a "clean" (unwatermarked) image and a per-pixel alpha
accumulator through the same sequence of operations -- every augmentation
parameter the generator draws (scale, rotation, opacity, blend mode, JPEG
quality, noise, colour shift, resize, ...) has to land in exactly the same
place in the shared `random`/`np.random` call sequence as it did when the
reference dataset was generated, or the replay silently desyncs and stops
matching the reference images pixel-for-pixel. Any edit to this file --
even a whitespace change that alters a line's behaviour, or reordering two
independent statements -- can change that call sequence. If the upstream
generator ever needs to change, copy the new version in whole and re-run
`replay_alpha_targets.py`'s exactness checks against a fresh reference
dataset generated by that same new version; never hand-edit this copy.

`replay_alpha_targets.py` is standalone (stdlib + numpy + PIL + cv2 only)
and documented in its own module docstring.
